Este proyecto es una de mis primeras pruebas dedesarrollo web para construir mi portfolio personal.

La idea fue crear algo un poco diferente a una página tradicional: una presentación interactiva donde pueda mostrar algunos de mis proyectos, tecnologías que estoy aprendiendo y parte de mi perfil como estudiante de Informática.

## Tecnologías utilizadas

* HTML
* CSS
* JavaScript

No utilicé frameworks en esta primera versión. Quise trabajar directamente con las bases del desarrollo web y experimentar con animaciones, transiciones, diseño responsive y navegación entre secciones.

## ¿Qué incluye?

Actualmente el portfolio muestra algunos proyectos relacionados con:

* QA y automatización de pruebas
* Python
* Java y Programación Orientada a Objetos
* Desarrollo de aplicaciones

La navegación se puede realizar con las flechas del teclado, los botones de la interfaz o haciendo click sobre la pantalla.

## Objetivo

Este proyecto forma parte de mi aprendizaje y de la construcción progresiva de mi portfolio.

Seguramente vaya modificándolo y agregando nuevos proyectos a medida que avance con desarrollo, testing, automatización e integraciones.
